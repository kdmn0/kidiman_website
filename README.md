# Kişisel Portfolyo Web Sitesi / Personal Portfolio Website

*(English version is below)*
## 🇹🇷 Türkçe

### Açıklama
Projeleri, yetenekleri ve iletişim bilgilerini sergilemek için oluşturulmuş modern, interaktif ve tamamen duyarlı (responsive) bir kişisel portfolyo web sitesi. Uygulama, olağanüstü bir kullanıcı deneyimi sunmak için 3D grafikler, akıcı animasyonlar ve pürüzsüz kaydırma gibi modern web teknolojilerini kullanmaktadır.

### Özellikler
- 🚀 **İnteraktif 3D Öğeler:** Sürükleyici bir görsel deneyim için Three.js ve React Three Fiber ile güçlendirilmiştir.
- ✨ **Akıcı Animasyonlar:** Framer Motion ile oluşturulmuş pürüzsüz sayfa geçişleri ve mikro etkileşimler.
- 📜 **Pürüzsüz Kaydırma (Smooth Scroll):** Yağ gibi akan, doğal hissettiren bir kaydırma deneyimi için Lenis entegrasyonu.
- 🌍 **Çift Dil Desteği:** `i18next` kullanarak yerleşik İngilizce ve Türkçe dil seçeneği.
- 📱 **Duyarlı (Responsive) Tasarım:** Tailwind CSS ile mobil, tablet ve masaüstü cihazlar için tamamen optimize edilmiş düzen.

### Kullanılan Teknolojiler (Tech Stack)
- **Frontend Framework:** React 19, Vite
- **Stil & Tasarım:** Tailwind CSS v4
- **Animasyonlar:** Framer Motion
- **3D Grafikler:** Three.js, React Three Fiber, React Three Drei
- **Kaydırma (Scroll):** Lenis
- **Çoklu Dil (i18n):** i18next
- **İkonlar:** Lucide React

### Kurulum / Başlangıç
Projeyi yerel bilgisayarınızda çalıştırmak için aşağıdaki adımları izleyebilirsiniz.

1. **Repoyu bilgisayarınıza klonlayın:**
   ```bash
   git clone https://github.com/kdmn0/kdmn0.github.io.git
   ```
2. **Proje klasörüne gidin:**
   ```bash
   cd kdmn0.github.io
   ```
3. **Gerekli paketleri yükleyin:**
   ```bash
   npm install
   ```
4. **Geliştirme sunucusunu başlatın:**
   ```bash
   npm run dev
   ```
5. Tarayıcınızı açın ve `http://localhost:5173` adresine gidin.

## 🇬🇧 English

### Description
A modern, interactive, and fully responsive personal portfolio website built to showcase projects, skills, and contact information. The application leverages modern web technologies including 3D rendering, fluid animations, and smooth scrolling to provide an exceptional user experience.

### Features
- 🚀 **Interactive 3D Elements:** Powered by Three.js and React Three Fiber for an immersive visual experience.
- ✨ **Fluid Animations:** Smooth page transitions and micro-interactions built with Framer Motion.
- 📜 **Smooth Scrolling:** Integrated with Lenis for a native-feeling, buttery smooth scroll experience.
- 🌍 **Bilingual Support:** Built-in English and Turkish language toggle using `i18next`.
- 📱 **Responsive Design:** Fully responsive layout optimized for mobile, tablet, and desktop devices via Tailwind CSS.

### Tech Stack
- **Frontend Framework:** React 19, Vite
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **3D Graphics:** Three.js, React Three Fiber, React Three Drei
- **Scrolling:** Lenis
- **Internationalization:** i18next
- **Icons:** Lucide React

### Installation / Getting Started
To get a local copy up and running, follow these simple steps.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/kdmn0/kdmn0.github.io.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd kdmn0.github.io
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Start the development server:**
   ```bash
   npm run dev
   ```
5. Open your browser and visit `http://localhost:5173`.
